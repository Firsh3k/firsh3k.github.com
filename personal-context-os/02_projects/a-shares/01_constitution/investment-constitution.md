# A股 Investment Constitution

Version: 4.0-draft.1  
Status: TEST  
Source baseline: ACTIVE principles from 《投资思想库》 + non-negotiable execution constraints from `SHARED_TRADING_RULES 2026.08.25-v3`.

This file contains durable principles only. It is not a daily market state, not a stock thesis, and not a report template.

## Market-level principles

1. **先市场、再赛道、再个股。** 市场收集器先于个股分析器；先确认是否有可交易环境，再确认资金去了哪里，最后才分析具体股票。
2. **先有势，再找强。** 无持续板块势，不因为单股故事漂亮而重仓；同一方向优先核心、龙头、中军或高辨识度标的。
3. **龙头是温度计，不是自动买点。** 龙头用于判断方向增强、分歧、修复、退潮，买入仍需通过位置、模型、触发和失效位。
4. **旧主线退潮时先找资金去向。** 不把全部研究资源用于等待旧主线反弹。
5. **市场候选 ≠ 交易候选。** 未补齐必要图表、结构、触发、失效和基本面事件证据，只能进入研究/补图队列。
6. **没有确认允许 0 笔交易。** Final3/候选池是注意力队列，不是强制买入清单。
7. **不猜绝对底顶，主要吃确认后的鱼中段。** 市场“确认声音”必须是价格、均线、量价、广度、风格、龙头和 T+1 承接等可验证证据。

## Stock and execution principles

8. **每只股票先过四道门：** 有效主线、核心地位、明确交易模型、清晰且距离合理的失效位。关键门不通过，不给主动主攻资格。
9. **左侧与右侧必须分开管理。** 左侧靠充分回撤、支撑、止跌、承接和小仓试错；右侧靠突破、站稳、首次有效回踩和趋势确认。
10. **正常买入只允许 L1 / R1；其余默认 X。** L1=暴跌后底部区间确认；R1=右侧趋势初转/首次有效回踩；连续加速、临近强压、失效位不清等归 X。
11. **不接下跌飞刀。** MA5-D0/持续创新低/均线仍下行时原则上不新开仓。
12. **进入支撑区不等于买点成立。** 至少要出现停止创新低、承接、抛压衰减或缩量、重新转强，并有失效位。
13. **强势股深跌后，先按反弹概率管理。** 深跌改善赔率，不证明主升重启。
14. **反弹与趋势分账。** 尚不能区分时默认按反弹风险预算；只有新增结构、板块、龙头与 T+1/T+2 证据持续成立才升级趋势。
15. **R0-R4：** R0持续下跌不接；R1观察；R2反弹确认/主要执行区；R3接近压力开始兑现；R4只有趋势证据成立才升级趋势。
16. **右侧优先突破、站稳、第一次有效回踩。** 错过早段后不在第二、第三根加速阳线追中后段。
17. **MA5/MA60 金叉只是预警，不是独立买点。** 必须结合 MA60 斜率、股价站位、赛道共振、量价、失效距离及 T+1/首次有效回踩。
18. **筹码分布是成本模型，不是主力真实账户成本。** 筹码峰和成本区只能作为结构证据，不能当绝对底、庄家成本或“不会亏”的保证。
19. **盘感只发预警，证据才允许下单。** 直觉必须翻译成量价、相对强弱、关键位、分时承接或龙头状态。

## Position and risk principles

20. **首笔只用于验证。** 仓位由市场状态、模型确认度、失效距离和风险预算决定，不由兴奋、跌幅或固定金额决定。
21. **加仓必须来自新增证据。** 股价上涨本身不是提高信念、延长持有或追加仓位的充分理由。
22. **不因浮亏、跌得多、接近成本或进入支撑区补仓。** 补仓只能发生在承接确认或趋势重新确认之后。
23. **安全成本来自可定义风险，而不是最低价格。** 离错误点近、上行空间相对足够，比“看起来便宜”更重要。
24. **同主线集中度受控。** 战备池同主线原则最多2只；Final3原则最多1只；已有同赛道持仓时需合并计算风险暴露。
25. **真实持仓 P0 风险管理优先于寻找新机会。** P0 不因“已经持有”自动获得主线或主攻资格。

## Exit and behavior principles

26. **买入先想退出，买卖逻辑必须一致。** 反弹仓不能无证据按趋势仓持有；趋势仓也不能因短线波动随意改成防守仓。
27. **卖出使用 S0-S4 分层，而不是临盘情绪。** S0持有、S1第一减仓、S2第二减仓/核心压力兑现、S3弱反弹退出、S4趋势失效/硬退出。
28. **非紧急明显减仓/清仓应用 2+1 防误卖闸门。** 至少2项客观市场降级证据 + 1项个股失效证据；只有主观“大盘要跌”不足以清仓。
29. **相对强势保护。** 赛道有效、个股相对强且未破位时，主观市场担忧不得直接全清；S4或突发重大风险不受此保护限制。
30. **卖后上涨不自动证明卖错，卖后下跌也不自动证明卖对。** 评价交易先看事前计划与当时可得证据。
31. **真实交易按 M/E/R/P/N/L 复盘。** 模型错误、执行错误、风控错误、心理错误、正常试错、运气收益必须分开。
32. **单日盈亏不得直接修改正式规则。** 新观察先进入研究课堂；达到样本与复审要求后再升级 Strategy Context。

## Portfolio and ranking principles

33. **排序优先级不是“谁涨得最多”。** 市场总开关 > 市值/指数环境 > 行业主线与生命周期 > 个股映射纯度和地位 > 模型/真实触发 > 失效与风险收益 > MA5/筹码/量价 > 攻击力。
34. **攻击力高 ≠ 应买；执行力高 ≠ 必买。** 两者都是信息压缩，不得越过市场、触发和风险边界。
35. **数据缺失必须降级。** `未提供 / 待确认 / 检索失败` 不能被写成确定结论；搜索失败 ≠ 没有公告，缺图 ≠ 没有风险。
36. **事实、策略推导和模型判断分层表达。** 任何推断都不得伪装成原始数据或公司事实。

## Governance

- 本 Constitution 只收录 `ACTIVE` 的稳定原则。
- `OBSERVE` 工作假设与 `REJECTED` 危险信念不得进入生产执行权限。
- 日常市场或个股状态变化不修改 Constitution。
- 修改本文件属于体系级变更，必须进入 Draft → Test → RC → Active，并保留 changelog 与 rollback。
