# Evidence Policy

Every material conclusion should be distinguishable from the evidence that supports it.

## Evidence levels

### E1 — Raw / Structured Fact
Directly observed or structured data: prices, dates, measurements, uploaded records, machine-readable values.

### E2 — Primary Source
Official announcements, filings, contracts, original publications, first-party statements, authoritative records.

### E3 — Verified Secondary Source
Reliable secondary data providers, reputable reporting, independently verified reference sources.

### E4 — Framework / Strategy Inference
A conclusion produced by applying an explicit project rule or framework to E1–E3 evidence.

### E5 — Model Judgment
A reasoned synthesis, forecast, prioritization, or recommendation that is not itself an observed fact.

## Rules

- Never present E4 or E5 as E1/E2.
- Time-sensitive claims must carry an effective/source date where practical.
- A missing source is not permission to fabricate one.
- When evidence is insufficient, lower confidence or state the gap.
- High-impact decisions should preserve the evidence trail used at decision time.
